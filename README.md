## 功能特性

### 布局与外观

- **四种壁纸形态**：关闭 / 横幅 / 全屏 / 全屏透明，前台可切换、后台定默认
- **全屏布局二选一**：经典（壁纸随文档滚动）/ Hero（首屏固定在视口，内容滚动上推，
  标题随滚动淡出、壁纸逐步虚化）
- **侧栏位置**：部件栏可在左 / 右之间切换，两栏布局下与内容对调、三栏布局下与右侧栏
  对调，内容始终居中
- **两栏 / 三栏自由切换**，可选的分类导航栏
- **卡片外观**：卡片描边与轻投影、卡片底色跟随主题色相、卡片悬浮抬升、磨砂玻璃导航栏
- **亮暗模式**（含 4 种切换动画）与主题色相自由调节
- **渐变过渡**：壁纸与页面背景衔接处加一层渐变，消除生硬接缝
- 4 档动画速度预设，可细化到 8 个时长变量

### 内容与阅读

- **沉浸阅读**：一键收起导航栏、两侧栏、目录与浮动按钮，正文收成单栏居中并限制行宽；
  右上角常驻出口按钮与 `Esc` 都能退出，状态跨页保持
- **字数与阅读时长**：中日韩字符按「字」计、其余按词计（中文博客常混排，只按一种算
  会严重偏差），阅读速度取中文 400 字/分钟、西文 200 词/分钟
- **相关推荐**：按同分类推荐，没有分类时退回同标签；自身会被滤除，同分类不足两篇时
  整个区块不显示
- **文章目录**：侧栏 / 右列 + 移动端弹窗
- 上一篇 / 下一篇、版权声明卡片、置顶文章高亮、分享海报（含二维码）、文章打赏
- **代码块增强**：语言徽章、行号、长代码块折叠、一键复制；外观对齐 Firefly
  （灰底标题栏 + 三枚低透明度圆点、one-light / one-dark-pro 两套 Shiki 配色）

### 动效与特效

- **樱花特效**：整屏飘落的花瓣，程序化绘制（不打包任何来历不明的图片素材），片数可配
  上限 100，尊重 `prefers-reduced-motion`，页面不可见时自动暂停
- **评论弹幕**：把该页已有的评论渲染成从右向左滚动的胶囊弹幕。留言板放在「留言板」
  欢迎卡片内（欢迎语下方，一条虚线分隔），文章页独立成卡。
  数据走 Halo 的评论公开 API（不从评论区 DOM 抓，评论插件换版本也不受影响），
  胶囊跟随主题色、亮暗两套，站长本人的评论单独高亮；悬停暂停、点击滚到评论区。
  需要先装评论插件（见「插件兼容」）
- **Banner 底部波浪**、渐变过渡、壁纸轮播
- **移动端底部导航**：固定底栏，条目（首页 / 归档 / 分类 / 标签 / 搜索 / 顶部）逐项可配；
  启用后页面自动留白，浮动按钮同步上移避让

### 侧边栏小组件

公告、个人简介（含在线状态）、天气、音乐播放器、一言、站点统计（9 项可选）、分类、
标签、热门文章、**写作热力图**（近半年发文密度，格子跟随主题色）、自定义 HTML、日程、
目录

### 独立页面

- **RSS 订阅页**：订阅地址（一键复制 + 结果提示）、推荐阅读器、最新文章、RSS 说明
- **打赏支持页**：引导文案 + 打赏方式（微信 / 支付宝收款码，或爱发电 / ko-fi 这类外链）
  - 打赏列表（名称 / 金额 / 日期 / 头像，可整块关掉）。全部内容在后台维护，纯服务端渲染
- 朋友圈、时间轴、技能、心愿便签等插件页面模板

### 站点与生态

- **首页社交链接**：标题下方一排按钮（GitHub / 邮箱 / 打赏 / RSS），每一项填了才显示
- **页脚站点运行时间**：「本站已运行 x 天 x 小时 x 分钟 x 秒」，秒数实时走动，可点击跳转
- **搜索**：直接调用 Halo 搜索索引 API，面板内实时结果
- **评论**：对接 Halo 评论插件
- **友情链接**：申请流程 / 随机访问 / 折叠面板 / 页脚卡片墙 / 朋友圈动态流
- **页脚链接栏**：多栏链接区（导航 / 组织 / 协议 / 友链这种），栏目标题与链接都可在后台配，
  数据直接复用 Halo 菜单，排序与层级用菜单编辑器维护
- **访客自定义**：导航栏「显示设置」面板，访客可自行切换布局、配色、壁纸、特效；
  站长可用总开关一键收回（关闭后面板入口整体隐藏，所有人看到的都是你配好的样式）
- 图片 CDN 实时压缩（8+ 图床规则）、外链跳转提示
- 认证页（登录 / 注册）、菜单图标后台可配
- 多语言：简体中文 / 繁體中文 / English

## 安装

1. 从 [Releases](https://github.com/only1nn/halo-theme-Onlynn/releases) 下载最新
   `onlynn-<版本>.zip`
2. 进入 Halo 后台 →「外观」→「主题」→ 右上角「安装」→ 上传 zip
3. 安装完成后点「启用」
4. 进入「主题 → 设置」按需调整（大多数功能默认关闭，按需开启即可）

> 主题 ID 为 `onlynn`（Halo 要求主题 ID 只能小写），后台显示名为 **Onlynn**。

## 主题设置

后台「主题设置」按功能分为 10 个分组，常用的几处：

| 分组         | 能配什么                                                                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **布局设置** | 页面布局（两栏 / 三栏）、移动端底部导航、Banner 形态、文章卡片布局、菜单栏、浮动按钮、欢迎弹窗                                                                 |
| **样式设置** | **显示设置面板**（访客权限 + 各项默认值）、Banner 样式与壁纸、标题与副标题、首页社交链接、配色方案、主题语言、样式开关、樱花特效、评论弹幕、动画速度、外部字体 |
| **侧边栏**   | 左右栏各放哪些小组件，以及每个小组件的详细配置                                                                                                                 |
| **文章**     | 版权声明、相关推荐、文章信息（字数 / 阅读时长）、代码块、内容显示、目录、摘要、操作栏（含沉浸阅读）                                                            |
| **扩展页面** | 朋友圈、时间轴、技能、RSS 订阅页、打赏支持页                                                                                                                   |
| **页脚**     | 站点运行时间、备案信息、链接显示、自定义链接、页脚友链、页脚链接栏                                                                                             |

> **「样式设置 → 显示设置面板」是外观配置的统一入口**：上半部分控制访客能改哪些项，
> 下半部分是该面板各项的**默认值**。想让所有访客都看到同一套样式，把「允许访客切换
> 样式」总开关关掉即可 —— 那时前台不再显示设置按钮，也不存在任何 per-browser 状态。

### 评论弹幕怎么配

「样式设置 → 评论弹幕」的每一项：

| 字段         | 默认       | 说明                                                                                                      |
| ------------ | ---------- | --------------------------------------------------------------------------------------------------------- |
| 启用         | 关         | 总开关。关闭时幕布不渲染，连 `danmaku.js` 都不会下载                                                      |
| 显示范围     | 仅留言板   | 仅留言板 / 仅文章页 / 所有带评论的页面                                                                    |
| 滚动基准秒数 | 14         | 一条弹幕横穿幕布所需秒数，越小越快；所有弹幕速度一致（长评论不会跑得更快）                                |
| 轨道数       | 5          | 分几行滚动。窄屏自动减半；幕布高度装不下时会再自动下调，不会叠在一起                                      |
| 同轨最小间距 | 24         | 同一条轨道上前后两条之间最少留出的像素                                                                    |
| 不透明度     | 0.9        | 胶囊的不透明度                                                                                            |
| 显示头像     | 开         | 有头像用头像；邮箱访客没有头像，用昵称首字 + 名字哈希配色代替                                             |
| 最多显示条数 | 30         | 按时间倒序取最近若干条                                                                                    |
| 幕布高度     | 180        | 像素。只需容纳设定的轨道数                                                                                |
| 循环播放     | 开         | 播完重新开始，避免幕布空着                                                                                |
| 点击弹幕     | 滚到评论区 | 评论插件的逐条锚点在它自己的 shadow root 里，跨 provider 不可靠，所以默认只滚到评论区；也可设为不响应点击 |

访客能在「显示设置 → 特效」里自己开关（前提是「访客可调样式 → 弹幕留言切换」为开）。

### 打赏页怎么配

「扩展页面 → 打赏支持页」的每一项：

| 字段         | 说明                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 副标题       | 显示在页面标题下方，留空用默认文案                                                                                             |
| 引导文案     | 页面顶部的主文案，留空用默认文案                                                                                               |
| 打赏用途     | 说明打赏会被用在哪里；留空则整块不显示                                                                                         |
| 打赏方式     | 每项一张卡片。**填了收款码就展示二维码，只填链接就显示「前往打赏」按钮**（两者都填时优先二维码）；两样都没填的项不会出现在前台 |
| 显示打赏列表 | 关掉后前台不显示整块                                                                                                           |
| 打赏列表     | 每项：名称 / 金额 / 日期 / 头像。名称填「匿名」就是匿名展示；头像留空用名称首字                                                |
| 结尾致谢     | 显示在打赏列表下方，留空则不显示                                                                                               |

打赏方式里的**图标**留空会按名称自动匹配：微信 / 支付宝用品牌图标，名称含「发电」用捧心、
含「ko-fi」用咖啡杯，其余用爱心；也可以自己从图标选择器里挑一个。

> 一个打赏方式都没填时，页面会显示一句「博主还没有配置打赏方式」的提示，而不是留一块空白网格。

## 菜单与路径

Halo 后台「外观 → 菜单」里新建菜单项时，**「链接」一栏填路径即可**（如 `/archives`），
Halo 会自动拼上站点域名；也可以填完整外链（`https://example.com`），此时建议勾选「新窗口打开」。
菜单项还可以配 Iconify 图标（主题已注册菜单注解，后台菜单项表单里有图标字段）。

### 页脚链接栏也用菜单

「主题设置 → 页脚 → 页脚链接栏」的多栏链接直接读 **Halo 菜单**，不另建一套配置：

1. 到「外观 → 菜单」新建一个菜单（比如叫「页脚」）
2. **一级菜单项**填栏目标题（如「导航」「组织」「协议」「友链」），自身链接随便填或留空
3. 在每个一级项下面**添加子项**，子项才是真正要显示的链接
4. 回「主题设置 → 页脚 → 页脚链接栏」：打开开关、选中这个菜单、选每行列数；
   「区块标题」可留给链接栏加一行居中标题（与页脚「友情链接」同款样式），留空则不显示

好处是排序、层级、图标都能用 Halo 原生的菜单编辑器维护。一级项如果没有子项，会把
自身当作该栏唯一链接显示，不会出现空栏；不需要某个栏目时删掉对应的一级项即可。

下表是主题实际提供的全部可访问路径，按来源分三类。

### 一、主题自带（装好即用）

| 菜单名称   | 链接填               | 说明                                        |
| ---------- | -------------------- | ------------------------------------------- |
| 首页       | `/`                  | 站点首页                                    |
| 归档       | `/archives`          | 全部文章按时间归档                          |
| 分类       | `/categories`        | 分类总览（点进去是各分类）                  |
| 标签       | `/tags`              | 标签总览                                    |
| 单个分类   | `/categories/{slug}` | `{slug}` 换成分类别名                       |
| 单个标签   | `/tags/{slug}`       | 同上                                        |
| 单篇文章   | `/archives/{slug}`   | 文章的永久链接                              |
| 自定义页面 | `/{slug}`            | 后台「页面」里新建，`{slug}` 就是页面的别名 |

> 文章与页面的实际路径取决于后台「设置 → 文章」里的**永久链接规则**，
> 上面是默认规则（文章 `/archives/{slug}`、页面 `/{slug}`）。改了规则就以实际访问地址为准。

### 二、主题提供的页面模板（需要自己新建页面）

后台「页面 → 新建」，在**「高级 → 自定义模板」**里选对应模板，再把「别名」设成建议值：

| 模板         | 别名建议填  | 说明                                                        |
| ------------ | ----------- | ----------------------------------------------------------- |
| **留言板**   | `guestbook` | 居中的引导卡片 + 评论区；页面正文可留空，也可用来自写欢迎语 |
| **RSS 订阅** | `rss`       | 订阅地址（一键复制）、推荐阅读器、最新文章、RSS 说明        |
| **朋友圈**   | `friends`   | 动态流页面，需「链接管理」插件                              |
| **心愿便签** | `wishes`    | 心愿墙 / 树洞便签墙，需「心愿便签」插件                     |
| **时间轴**   | `timeline`  | 个人历程时间轴，数据在主题设置里配                          |
| **技能**     | `skills`    | 技能展示，数据在主题设置里配                                |
| **打赏支持** | `sponsor`   | 打赏方式（收款码 / 外链）+ 打赏列表，数据在主题设置里配     |

> 别名可以随意取（比如把 RSS 页放在 `/feed`），上面的只是建议值；
> 主题的「首页社交链接」里 RSS 按钮默认指向 `/rss`，改别名的话记得同步改。
> 打赏页建好后，把它的地址填进「样式设置 → 首页社交链接 → 打赏页地址」，
> 首页副标题下方就会出现打赏入口。

### 三、插件提供的路径（装了对应插件才有）

| 插件     | 链接填               | 说明                                |
| -------- | -------------------- | ----------------------------------- |
| 瞬间     | `/moments`           | 列表页；`/moments/{name}` 是详情页  |
| 图库     | `/photos`            | 列表页；`/photos/{name}` 是详情页   |
| 链接管理 | `/links`             | 友链页；支持 `?group=` 按分组筛选   |
| B 站番剧 | `/bangumis`          | 追番列表                            |
| 日程日历 | `/schedule-calendar` | 日程页                              |
| 装备管理 | `/equipments`        | 装备展示；支持 `?group=` 筛选       |
| 项目集   | `/projects`          | 列表页；`/projects/{slug}` 是详情页 |

以上页面模板主题都已适配，装上插件即可直接访问。

### 认证页（Halo 内置）

`/login` 登录、`/signup` 注册、`/logout` 退出、`/password-reset` 找回密码。
一般不必放进菜单，主题会在需要时自动跳转。

### 目前不支持

**作者归档页**（`/authors/{name}`）：主题未提供 `author.html` 模板，访问会返回 404
（这是从基座继承下来的，上游同样没有）。分类与标签归档都可用。

## 插件兼容

主题对插件采取「有则增强、无则降级」的策略：插件缺失时相关模块会整块跳过，不会报错。

已做深度整合的插件：

| 插件      | 用途                                         |
| --------- | -------------------------------------------- |
| 搜索      | 导航栏搜索面板（调用 Halo 搜索索引 API）     |
| 评论      | 文章 / 页面 / 瞬间 / 图库的评论区            |
| 瞬间      | 瞬间列表与详情页                             |
| 图库      | 相册列表与详情（PhotoSwipe 灯箱 + EXIF）     |
| 链接管理  | 友链页面、申请流程、页脚卡片墙、朋友圈动态流 |
| 项目集    | 作品集列表与详情                             |
| 装备管理  | 装备展示页                                   |
| 心愿便签  | 心愿墙 / 树洞便签墙                          |
| 日程日历  | 日程页面与侧栏小组件                         |
| B 站番剧  | 追番页面                                     |
| extra-api | 站点总字数统计                               |

推荐一并安装：**Feed**（RSS 订阅）、**Sitemap**、**Shiki**（代码高亮）、**lightgallery**。

> **评论弹幕不依赖评论插件**：弹幕只读 Halo 的评论公开 API，页面上的
> `haloCommentEnabled`（只有在插件实现了 `CommentWidget` 扩展点时才为真）与它无关 ——
> 用自带 UI 的评论插件时评论区可能不渲染，但弹幕照常工作。
> 只要库里有评论、后台「样式设置 → 评论弹幕」总开关打开、页面命中「显示范围」，
> 弹幕就会出现（没有评论时整块自动收起）。

> **Shiki 插件配置建议**：安装后把「风格」设为 `simple`、「亮色主题」设为 `one-light`、
> 「暗色主题」设为 `one-dark-pro`，与主题的代码块外框正好配套。「Mac 窗口」风格自带
> 标题栏，会与主题提供的外框重复。

## 写模板时要注意的坑

这个项目的构建链路是「Astro 编译出 Thymeleaf 模板」，两边的心智模型交织，容易踩坑。
改模板前建议读一遍 `AGENTS.md`，其中几条高频的：

- **`th:if`(300) 先于 `th:with`(400) 求值**：把 `th:with="x=…"` 和引用 `x` 的 `th:if`
  写在同一元素上，`th:if` 求值时 `x` 还不存在，整块会**静默不渲染**。要用外层
  `<div th:remove="tag">` 承载 `th:with`，条件写内层。
- **Astro 的 `<style>` 默认带作用域**：脚本用 `document.createElement` 动态生成的节点
  没有作用域属性，选择器匹配不到，样式会静默失效。动态节点要用 `<style is:global>`
  加容器前缀。
- **面板项的默认值必须服务端渲染**：首帧脚本只负责套用访客覆盖。若只靠脚本套覆盖，
  访客开关一关元素就会掉回 CSS 原始默认，站长的配置等于失效。
- **`pnpm build` 只做 Astro 侧编译**，看不到 Thymeleaf 的服务端错误。改完模板要装进
  Halo 实跑一次。
